# Moteki App POS

Moteki App POS est une application de caisse (point de vente) pour commerces : ventes, stock, ventes à crédit, multi-devises, rapports de caisse et impression de tickets.

Ce dépôt sert uniquement à distribuer les APK Android. Il ne contient pas le code source de l'application.

## Télécharger

➡️ **[Dernière version (APK Android)](https://github.com/moteki-app/moteki/releases/latest)**

Sur le téléphone, ouvrez le fichier `.apk` téléchargé et autorisez l'installation depuis cette source si Android le demande.

- Package : `com.motekiapp.pos`
- Android 7.0 (API 24) minimum
- Chaque release indique l'empreinte SHA-256 de l'APK pour vérifier le fichier.

Site : https://www.motekiapp.com
